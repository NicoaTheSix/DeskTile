# 桌面拼格 DeskTiles 使用說明

桌面拼格可在桌面擺放六角形、三角形、矩形，用來顯示文字、圖片、計時器或鬧鐘。每格可獨立置頂或固定於桌面層，也能多選一起移動與修改外觀。

## 從這裡開始

1. 下載 `DeskTiles-Windows-x64.zip`，完整解壓縮。
2. 開啟解壓後的 `DeskTiles` 資料夾，雙擊 `DeskTiles.exe`。
3. 第一次啟動會顯示三個示範格與內容控制視窗。
4. 在控制視窗左側選擇格子，右側輸入內容，按「套用至所有選取格」。

使用版適用 Windows 10／11 x64，不需要安裝編譯器、Python、.NET 或額外執行套件，不需要管理員權限。Linux 版本尚未實作。只下載原始碼專案時需要自行建置；免安裝 ZIP 已包含建置完成的 EXE。

## 切換語言

控制視窗右上角的「語言 / Language」選單可選 **繁體中文** 或 **English**；圖形右鍵與系統匣選單也有語言入口。選擇後立即更新介面，不需要重開。

主視窗、設定視窗、選單、提示、圖形狀態與錯誤訊息皆支援英文。切換會保留尚未套用的內容、字體、數值、核取選項、文字選取與目前多選；正在運行的計時器不會被重設。格子自己的文字、圖片路徑與字體名稱維持原內容，不會自動翻譯。

偏好存於資料目錄的 `ui-settings.json`，下次啟動自動沿用；預設繁體中文。這份偏好不屬於 JSON 版面，匯入配置不會改變介面語言。設定檔損壞時會使用預設語言，保留原設定檔；若無法保存選擇，會顯示原因並保留目前語言。Windows 系統檔案與選色對話框的可用語言由系統資源決定。

英文操作說明見 [UserGuide.en.md](UserGuide.en.md)。

## 新增、選取與移動

- 左側形狀選單預設六角形，可選朝上正三角形或 3:2 矩形，再按「＋新增圖形」。右鍵與系統匣也可新增。
- 按下圖形時立即更新主選取與右側內容面板。Shift＋單擊加入或取消多選；取消主格後會改選仍在多選中的格子。直接單擊已選取的一格會改成單選，開始拖曳則保留原多選。
- 從任一選取格拖曳即可移動整組，保持彼此的相對位置。按住 Shift 也可整組拖曳；只有原地單擊才取消該格。快速連按後直接拖曳仍可移動，單純雙擊則在放開後開啟控制視窗。
- 靠近其他格會吸附；不同形狀優先對齊邊中點或角點，也能沿邊吸附。放開後若重疊會回到原位。
- Esc 取消選取。雙擊圖形重新開啟控制視窗。
- 圖形右鍵可將選取格設成「顯示於最上層」或「固定於桌面層」。

## 文字、圖片與計時器

先選取圖形，再從右側內容類型選文字、圖片、計時器或鬧鐘。

- **文字**：支援中文、多行與置中顯示；輸入後按套用。
- **圖片**：瀏覽 PNG、JPEG 或 BMP 後按套用，圖片依格子形狀等比例裁切。直接選取的圖片會引用來源路徑；要一起備份或搬到別台電腦，請匯出 JSON。
- **計時器**：可選倒數或正向計時，倒數輸入總秒數後按套用，再按開始／暫停或重設。可在「文字內容」填入任務名稱，格子會同時顯示文字與時間。程式結束後保存已計時間，下次開啟維持暫停。

多選時按套用會改動所有選取格的內容。只想調外觀時，使用左側獨立的外觀設定按鈕。

## 鬧鐘與自訂文字

1. 選取一個或多個圖形，內容類型選「鬧鐘」，填入「文字內容」，例如「下午開會」。
2. 按「鬧鐘設定…」，日期填 `YYYY-MM-DD`，時間填 24 小時 `HH:MM`。
3. 預設「單次」；可改為「每天」或「指定星期」。指定星期至少勾一天。日期只用於單次模式。
4. 勾選「啟用鬧鐘」，按「套用鬧鐘與文字至選取格」。單次啟用時間必須在未來。取消勾選後按套用即可停用。
5. 同一格顯示時間、自訂文字，以及日期／星期與啟用狀態。只改文字時在控制視窗編輯後套用，保留原有鬧鐘時段。

到期時會有系統提示音、系統匣通知及可關閉的提醒視窗；多個提醒保留最近十筆。系統音量或通知是否開啟由 Windows 設定決定。提醒不會阻塞其他計時器。

程式必須在執行中，時間依 Windows 本地時鐘。睡眠期間到期，喚醒後補提醒一次；關閉期間不會響鈴。重新啟動時，過期單次鬧鐘會停用，重複鬧鐘排到下次時段，不會補響關閉期間的舊事件。夏令時間不存在的時刻略過當日，重複時刻當日只提醒一次。

鬧鐘與文字會保存到版面及含圖片的 JSON；匯入仍可選覆蓋或合併。新版讀取舊版配置，新保存的配置使用原生 v6／JSON v3，舊版本無法讀取新格式。

## 開機登入後自動啟動

此選項**預設關閉，程式不會替你啟用**。

- 在控制視窗下方勾選「Windows 登入後自動啟動（需同意）」。
- 確認視窗顯示實際程式與資料目錄的絕對路徑；只有選「是」才會啟用。「否」是預設選項，取消或關閉確認視窗都不會啟用。
- 取消勾選即可停用。只會移除 DeskTiles 自己的啟動設定。
- 登入啟動會載入原資料、顯示格子與系統匣，控制面板保持隱藏；點系統匣或雙擊格子可開啟面板。
- 此選項不包含在 JSON；匯入、更新或一般啟動都不會自行啟用。搬動 EXE 或資料目錄後，請於新位置取消勾選，再重新勾選並同意，以更新路徑。

## 大小、字體與邊框

- 「大小與文字…」可分別勾選套用大小、文字樣式。寬度 80～480 px，字級 8～96 px；字體清單列出本機已安裝且可繪製的字體，文字顏色可輸入色碼或選色。當文字或計時數字放不進圖形時，會縮小實際顯示字級（最低 8 px），原設定仍保留；內容過長時顯示省略符號。缺少字體時優先使用支援中文的替代字體。
- 多選調整大小會等比例改變位置；空間不足時保留原設定。
- 「邊框與風格…」支援實色、像素、RGB 彩虹與單色呼吸燈。厚度 1～12 px，動畫週期 2～60 秒，可修改顏色與停止播放。
- 「背景與透明度…」可分別套用背景色與透明度。0% 不透明、100% 完全透明；只影響背景，文字、圖片與邊框保持原設定。完全透明的空白區仍可選取與拖曳。
- 設定視窗修改後必須按套用。控制介面的預設字級為 18 px，頁首標題為 32 px；與每格內容字級分開設定。

## 保存、備份與換電腦

一般操作完成後會自動儲存。預設資料位置為 `%LOCALAPPDATA%\HexDesk`；保留此舊名稱以維持版本相容性。啟動時會顯示實際輸入／輸出絕對路徑。

右上角「配置 JSON…」提供：

1. **匯出整體配置**：保存全部格子、位置、樣式及圖片內容，成為單一 JSON。
2. **覆蓋匯入**：以 JSON 取代目前配置，先確認並備份。
3. **合併匯入**：保留目前格子，匯入新格並分配新 ID；必要時整組平移以免重疊。

套件中的「範例配置.json」含三種形狀及一張示範圖片，可用合併匯入試用。圖片內容已內嵌，匯入後保存到資料目錄的 `assets`。字體只保存名稱；別台電腦沒有該字體時會提示並使用替代字體。

JSON 限制：最多 500 格；每張圖片 16 MiB、圖片總量 64 MiB、JSON 128 MiB、圖片解析度 6400 萬像素。格式錯誤或圖片損壞時不修改目前版面。

## 關閉、結束與更新

關閉控制視窗只會隱藏控制面板，桌面圖形與計時器繼續運作。再次雙擊圖形或點系統匣可開啟控制面板。

要結束程式，先套用尚未提交的編輯，再從圖形右鍵或系統匣選「儲存並結束桌面拼格」。要使用更新版，也先結束舊版，再執行新的 EXE；版面會從相同資料位置還原。

重複執行相同資料目錄時，程式會帶回既有控制視窗。它不會同時啟動兩份程式寫入同一個版面，也不會自動結束舊版。

## 打不開時

- 若舊版仍在背景執行：新版通常會帶回舊版視窗。請先從系統匣儲存並結束，再開新版本。
- 若顯示資料目錄不可寫：檢查提示中的實際資料位置與 Windows 錯誤碼，或指定另一個可寫入目錄。
- `session.lock` 留在資料夾是正常情況，檔案是否存在不代表程式正在執行；不要靠刪除鎖檔解決重複啟動。
- 圖形找不到：從系統匣選「找回全部圖形」，會移到主螢幕並置頂。
- 圖片無法讀取：重新選擇來源圖片，或匯入包含圖片的 JSON。

需要獨立資料目錄時，在 PowerShell 執行：

```powershell
.\DeskTiles.exe --data-dir 'D:\DeskTilesData'
```

不同資料目錄可以分別執行，彼此不會改動對方版面。不同 Windows 版本、多螢幕、DPI 與 Explorer 重新啟動的相容性仍需持續驗收。

所選字體缺少內容中的中文字元時，整段內容會使用可完整顯示的中文字體替代，讓量測與繪製保持一致，避免字元重疊；原字體名稱與字級設定仍保留，純英文且受支援的內容維持選定字體。


## Windows：多套桌面配置與指令操作

在系統匣右鍵選「桌面配置」。你可以保存目前配置的副本、新增空白配置、重新命名，或點選清單直接切換。勾選項是目前顯示的配置。切換只會換畫面，其他配置裡的倒數和鬧鐘仍會運作，提醒會標出配置名稱。另存副本不會啟動第二組提醒；要使用副本的排程，可以再手動啟用。

先啟動 DeskTiles.exe。在 CMD 執行 `desktiles-cli.exe --help`，在 PowerShell 執行 `./desktiles-cli.exe --help`。常用指令如下：

```text
desktiles-cli.exe layout switch "工作"
desktiles-cli.exe tile list
desktiles-cli.exe tile add --shape hexagon --text "今日待辦"
desktiles-cli.exe tile update --id 1 --text "已完成"
desktiles-cli.exe tile hide --id 1
desktiles-cli.exe tile show --id 1
desktiles-cli.exe tile delete --id 1
```

請把範例的 `1` 換成 `tile list` 顯示的實際 ID。方塊指令可加 `--layout "配置名稱"` 操作指定配置。自訂資料目錄時，請在子指令前加 `--data-dir` 並使用與 App 相同的路徑。完整配置與 CLI 說明見專案 README。

## 鼠尾草綠樣板（Windows）

在系統匣選「桌面配置 → 從鼠尾草綠樣板建立…」，輸入新配置名稱。雙擊六角形筆記可修改文字。更換三角形照片時，在控制視窗選取其他檔案並套用，再從照片右鍵選「調整照片裁切…」拖曳或調整縮放。矩形倒數預設為 25 分鐘，按「開始計時」才會開始。

在「圖形大小與文字樣式…」勾選「套用大小」，可分別輸入矩形寬度及高度，留空高度使用 3:2。從右鍵選單可切換「隱藏編號與狀態標籤」。JSON 匯出包含照片和外觀設定。樣板會沿用目前桌布。
