## 可直接使用的專案介紹

**名稱：** 桌面拼格 DeskTiles

**短介紹：** 可自由拼排的 Windows 桌面小工具。將文字、圖片與計時器放進六角形、三角形或矩形，支援多選拖曳、自動吸附、置頂與桌面層，搭配透明背景、像素邊框、RGB 與呼吸燈。整體配置可透過含圖片的 JSON 備份、覆蓋或合併。

**英文摘要：** DeskTiles is a native Windows desktop widget app for arranging text, images and timers in hexagonal, triangular or rectangular tiles. It supports group dragging, snapping, desktop or always-on-top layers, transparent backgrounds, animated borders and JSON configurations with embedded images.

**語言：** 同一執行檔支援繁體中文與 English 即時切換，保留編輯並記住偏好。英文文件位於 `D:\DeskTile\docs\UserGuide.en.md`。

**技術：** C++17、Win32、GDI+、靜態 C++ 執行階段。

**使用條件：** Windows 10／11 x64。免安裝 ZIP 完整解壓後直接執行 EXE，不需 Visual Studio、Python、.NET 或額外執行套件。Linux 版本列為後續開發。

**驗證：** 179 項核心與 166 項 Windows 整合檢查通過；已從 ZIP 解壓後直接執行。重複啟動與舊版視窗帶回、版面不變、損壞資料保護亦有測試。效能數字屬本機短時間樣本，請保留場景與限制，避免當成所有電腦的保證。
